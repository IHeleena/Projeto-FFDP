Projeto: Apresentação de uma Banda
Este projeto foi desenvolvido como um exercício prático durante meus estudos de **HTML e CSS**, com o objetivo de treinar a estruturação de páginas web e aplicar os conceitos aprendidos em aula.
A ideia foi criar uma página para apresentar uma banda que eu costumava ouvir bastante na época, usando-a como referência para desenvolver o projeto e tornar o aprendizado mais divertido e pessoal.

Tecnologias utilizadas:
- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização dos elementos, cores, espaçamentos e layout.

Objetivos do projeto:
- Praticar a estruturação semântica com HTML.
- Aplicar conceitos básicos de estilização com CSS.
- Trabalhar a organização dos elementos na página.
- Desenvolver minhas habilidades de criação de páginas web.

Contexto:
Este é um mini projeto de caráter educacional, criado para colocar em prática os conhecimentos adquiridos em aula e ganhar mais familiaridade com o desenvolvimento front-end.
Mais do que apresentar uma banda, o projeto representa uma etapa do meu aprendizado e da minha evolução na programação.
*Projeto desenvolvido para fins de estudo e prática de HTML e CSS.*
